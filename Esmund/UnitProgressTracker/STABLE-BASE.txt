Unit Progress Tracker — current build (keeper)
==============================================

Version: 1.0.43
Marked: 2026-08-04

Source: Esmund/UnitProgressTracker in Detailing-Inventor-Projects (GitHub).

Run
---
  cd Esmund/UnitProgressTracker
  npm install          (first time only)
  py -3 -m pip install pywin32
  npm start
  — or double-click Start Unit Progress Tracker.vbs

Current build highlights (v1.0.41 → v1.0.43)
--------------------------------------------
- Per-project Status and Checklist templates saved in project JSON (projectOptions)
- Renamed surfaces stay visible after Save / Load Project
- Remove mistaken numbers from Surface history (Renumber & history panel)
- Autosave to project file when IAM sourceFolder is missing or on another PC
- Failed autosave no longer leaves the app stuck unable to close

Requires Node.js, Autodesk Inventor, Python 3 + pywin32.
Do NOT open index.html in a browser — use Electron (npm start or .vbs launcher).
