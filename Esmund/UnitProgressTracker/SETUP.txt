   npm install
   pip install pywin32
   npm start

Requires Node.js, Autodesk Inventor, and Python with pywin32 (same COM read as Pigeon).
Do NOT open index.html in a browser — use npm start (Electron).

Open a folder of 391Z*.iam files (subfolders scanned). Rescan adds new surfaces.
Opens blank on launch; use Open Folder or File → Recent.

File menu: Save/Load project (v3 portable save with geometry), Recent, Rescan, Import BOM, Import/Export.
BOM tab: import BOM xlsx, create Shell folder nest, open export folders in Explorer.
Resizable side panels · scan progress + cancel · cache-first folder load.
Options: grid, FPS toggle, mouse maps, fonts/colors, BOM list sort/filter.

npm install may show a deprecated-package warning and audit notices — normal for Electron; safe to ignore for local use.

If extracted from OneDrive/USB zip: unblock folder (Properties → Unblock) if Windows blocks scripts.
