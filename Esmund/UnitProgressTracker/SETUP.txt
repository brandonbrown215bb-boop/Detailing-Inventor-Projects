Unit Progress Tracker — GitHub source
Version 1.0.40 (2026-07-30)

Folder: Esmund/UnitProgressTracker (this repo)

1. Open PowerShell in Esmund/UnitProgressTracker
2. First time only:
   npm install
   py -3 -m pip install pywin32
3. Start:
   npm start
   — or double-click Start Unit Progress Tracker.vbs

Requires Node.js, Autodesk Inventor, Python 3 + pywin32.
Do NOT open index.html in a browser — use Electron.

See STABLE-BASE.txt and HOW_TO_USE.md for features and troubleshooting.
